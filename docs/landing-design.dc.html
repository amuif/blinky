Why Blinky

Small tag, lots of life

Same name, same face

Faces come from a seed, so a user looks the same on every page, device and visit.

Alive, not static

Online blinks and breathes, away gets sleepy, offline closes its eyes. Presence you can see.

htmlreactvuesvelte

Any framework

It is a standard web component. If your stack renders HTML, it renders Blinky.

Nothing to host

Drawn as SVG in the browser. No image uploads, no CDN of faces, no server calls.
